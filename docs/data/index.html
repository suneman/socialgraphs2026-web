Loading it

Both files are tab-separated with # comment headers; node ids are Wikipedia page titles with underscores. One thing to know: 17 of the 303 characters have no link in either direction, so if you build the graph from the edge list alone you get 286 nodes and silently lose the isolates — and the isolates are part of the story. Add every node first:

import pandas as pd, networkx as nx

nodes = pd.read_csv("week1_nodes.tsv", sep="\t", comment="#",
                    quoting=3)  # QUOTE_NONE: TSVs never quote, but blurbs may contain "quotes"
edges = pd.read_csv("week1_edges.tsv", sep="\t", comment="#",
                    names=["source", "target"])

G = nx.DiGraph()
G.add_nodes_from(nodes.node_id)
G.add_edges_from(edges.itertuples(index=False))
# G: 303 nodes, 1784 edges

Where it comes from

The snapshot was built 26 August 2026 from the live English Wikipedia, and two decisions in the pipeline are worth knowing about, because they are exactly the kind of decision §3 of week 1 is on about:

  • Edges come from the article text, not from Wikipedia's link index. The index counts links contributed by shared navigation templates — every Avenger carries the same team navbox, which would make whole rosters mutually adjacent by templating artefact, not because anyone's article mentions anyone. Here an edge means the running text of A's article actually links B.
  • Redirects are resolved on both ends, so [[Spidey]] and [[Spider-Man]] are one node, and a link to any alias still lands on the character.

Could you have made those choices differently? Yes — and you would have gotten a different network. That is the point of week 1, and when your project crawls a domain of its own, the choices are yours.
